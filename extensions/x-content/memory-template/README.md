# X Content Private Memory

Copy this directory outside the repository to a private location, then point the `x-content` extension's `workspace` source at that directory.

This workspace is domain/content memory. It is not Browser memory.

## Files

- `voice.md` — explicit account promise, audience, tone, and positioning.
- `patterns.md` — promoted content/reply patterns with evidence, confidence, and limitations.
- `results.md` — current measured account outcomes; fresher results outrank stale heuristics.
- `topics.md` — recurring pillars, active themes, backlog, and deprioritized topics.
- `examples.md` — curated URLs/short excerpts plus why they matter; avoid indiscriminate full-post dumps.
- `candidates.md` — proposed lessons awaiting explicit review/promotion.

Do not store credentials, cookies, tokens, private messages, or other secrets here.

Promotion is deliberate: observation -> candidate lesson -> review/evidence -> promoted knowledge.
