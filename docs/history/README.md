# Engineering History

This directory preserves design, benchmark, implementation-plan, coordination, and acceptance evidence from earlier development phases. It is **not** the current operating manual.

For current behavior, start with the repository [README](../../README.md) and the primary guides directly under [`docs/`](../).

The accepted Phase-2 checkpoint is the release tagged `personal-harness-phase2-2026-08-16`.

- [`benchmarks/`](benchmarks/) — measured experiments and acceptance evidence
- [`plans/`](plans/) — historical implementation plans
- [`specs/`](specs/) — historical design specifications
- [`agent-plans/`](agent-plans/) — parallel-agent coordination history
- [`acceptance/`](acceptance/) — superseded acceptance and migration procedures

Historical files intentionally keep their original dates, verdicts, and project-state language. When historical text conflicts with the current guides, the current guides and current tests are authoritative.
