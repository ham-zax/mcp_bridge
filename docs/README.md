## Current vs. historical docs

The files above describe the current accepted system.

Older benchmarks, design specs, implementation plans, agent coordination, and superseded acceptance procedures are preserved under [Engineering History](history/README.md). They are useful evidence, but they are not the operating manual.

Important old documentation paths remain as small compatibility pointers instead of duplicated stale guidance.
